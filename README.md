# Prism Path

A light-routing puzzle game. Turn glass tiles to carry white light from inlets to outlets, split it with prisms, bend it with mirrors and mix the colours each receiver needs. Each solved route plays a melody and becomes a line in the night sky. It has a 90-puzzle Journey across nine constellations, a weekday daily, the unscored Drift mode and the optional timed Pulse mode. There are browser and Swift Playgrounds editions.

The browser edition is the light-and-prisms build. [LIGHT-AND-PRISMS.md](LIGHT-AND-PRISMS.md) explains what changed from version 36, how each proposal item was handled, and what is still to do.

Sign-in providers need their own runtime configuration; see [SIGNIN_SETUP.md](SIGNIN_SETUP.md). Full Sky shows a planned price but takes no payment, and there are no advertisements. The native package has its own StoreKit and test-ad setup.

## Run the browser project

Use Node.js 24 and pnpm, and keep the supplied lockfile.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Open the local address Vite prints. The application uses server routes and a Cloudflare D1 binding, so it cannot be opened as a single HTML file. The local database starts empty. With the dev server running, apply the migrations once:

```sh
node scripts/local-db.mjs
```

Until then, player routes answer 503 and the game keeps progress in the browser.

## Verify and build

```sh
node --experimental-strip-types --test scripts/*.test.ts
pnpm exec tsc --noEmit
pnpm build
```

All 39 tests, TypeScript checking and the production build pass on this branch. These checks do not replace device, listening or real-provider testing; see [PLAYTEST.md](PLAYTEST.md).

To regenerate the puzzles, run `node --experimental-strip-types scripts/generate-content.ts`. The output is deterministic: the same code always produces the same file.

Deploying this build requires applying `drizzle/0002_light_and_prisms.sql` to the D1 database first.

## Swift Playgrounds edition

Open `native/playgrounds/PrismPath.swiftpm` in Apple's Swift Playgrounds, following [the preserved setup notes](native/playgrounds/START-HERE.md).

This is an earlier native edition and has none of the light-and-prisms changes. It was not compiled or device-tested during the import. The separate original Xcode archive those notes mention was not among the retrieved project files.

## History and provenance

The imported browser baseline is commit `bd89d7271857835b9e286940d799fb74fddf806f`, improvements version 36. The recovered source history includes the original browser version 4 at `26a4ed22348a6526d38bc108e481d1c4d56b8f6f`.

GitHub starts with a snapshot import of the prepared project. The original 42 source commits are indexed in `docs/source-history.json`. Their complete Git objects and history are preserved separately in the `prism-path-repository.zip` backup prepared for the owner. The hashes in that index identify the original sources; they are not commits in GitHub's snapshot history.

[docs/IMPORT.md](docs/IMPORT.md) lists the exact sources and the fingerprints of the preserved archives. Earlier development notes ([DEVELOPMENT-BUILD.md](DEVELOPMENT-BUILD.md), [REWARDED-JOURNEY.md](REWARDED-JOURNEY.md)) describe earlier snapshots.

This repository does not publish a new game version or activate payments, provider accounts or Apple distribution. Existing third-party license notices are retained, and no new open-source license is assigned.
